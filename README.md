# 🌦️ Weather Application

## 📌 Project Overview

Weather Application is a Java-based web application that provides real-time weather information for any city.

The application fetches weather data using OpenWeather API and displays details like temperature, weather condition, humidity, wind speed, and location.

This project is developed using Java Servlet, JSP, HTML, CSS, and JavaScript.

---

## ✨ Features

- 🌍 Search weather information by city name
- 🌡️ Display current temperature
- ☁️ Show weather conditions (Clear, Clouds, Rain, Thunderstorm, etc.)
- 💧 Display humidity percentage
- 🌬️ Display wind speed
- 🖼️ Dynamic weather icons based on weather condition
- 📱 Responsive user interface

## 🚀 Installation

Follow these steps to run the project locally:

### 1. Clone the repository

```bash
git clone https://github.com/sachin7518/java-weather-app.git
```

### 2. Open the project

Open the project in Eclipse IDE.

### 3. Configure Server

Configure Apache Tomcat Server with Eclipse.

### 4. API Configuration

Add your OpenWeather API key in the project configuration.

### 5. Run Application

Run the project on Tomcat Server.

### 6. Open in Browser

```
http://localhost:8080/WeatherApp/
```
